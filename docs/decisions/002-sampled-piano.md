# D2. Sampled piano

- **Date:** 2026-08-31 (recorded 2026-10-15)

The synthesized piano was replaced by Salamander Grand Piano samples (MP3), one every minor third. A note plays the
nearest sample, pitch-shifted by at most 1.5 semitones, so every generated note must stay inside the sampled range.
Samples are loaded and decoded once, on the first user gesture.
