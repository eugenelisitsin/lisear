# Decisions

One file per decision: `NNN-short-title.md`, numbered in order (D1, D2, …). Each says what was decided, why,
and — if it was later changed — which decision supersedes it. Code comments refer to them as "D5" etc.

**Adding one:** create the next file in the same pull request as the change it explains. If two open pull requests
pick the same number, the one merged second is renumbered when it is rebased. The directory listing is the index.

D1–D3 record decisions made before this log existed.
